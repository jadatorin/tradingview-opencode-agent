# Contribuir 🤝

¡Gracias por tu interés en contribuir!

## Pasos

### 1. Fork el repo
```bash
git clone https://github.com/jadatorin/tradingview-opencode-agent.git
```

### 2. Crea una rama
```bash
git checkout -b feat/mi-nueva-feature
```

### 3. Haz tus cambios
```bash
# Edita archivos
git add .
git commit -m 'feat: descripción de cambios'
```

### 4. Push y PR
```bash
git push origin feat/mi-nueva-feature
```

Luego abre un Pull Request en GitHub.

## Reglas

- Sigue [Conventional Commits](https://www.conventionalcommits.org/)
- Incluye tests si agregas funcionalidad
- Actualiza documentación si cambias comportamiento
- No agregues dependencies sin justificación

## Workflow de cambios

1. **Explora** — entiende el código existente
2. **Planifica** — crea un plan antes de codear
3. **Implementa** — código limpio y documentado
4. **Testea** — verifica que funcione
5. **Commit** — mensajes claros y convencionales

## Checklist antes de PR

- [ ] Código compila sin errores
- [ ] Tests pasan
- [ ] Documentación actualizada
- [ ] Commits siguen conventional commits
- [ ] No hay console.logs o debug code
